# إعداد Firebase لـStudyBuddy (مجاني، بلا بطاقة، حوالي ١٠ دقايق)

بيربط جهاز الأهل بجهاز الطالب: تقارير، حد وقت، واجبات، وإدارة الكتب من بعيد. اختياري: بدونو التطبيق بيشتغل كامل على جهاز واحد.

## ١) المشروع
1. افتح console.firebase.google.com وسجّل دخول بحساب Google.
2. **Create a project** ← اسم المشروع (مثلاً `studybuddy-family`) ← عطّل Gemini وGoogle Analytics ← Create.

## ٢) تسجيل الدخول (Authentication)
1. **Build ← Authentication ← Get started**.
2. تبويب **Sign-in method**: فعّل **Email/Password** وفعّل **Anonymous**.
3. **ما تفعّل "Auto clean-up"** للحسابات المجهولة: بيمسح أجهزة الطلاب بعد ٣٠ يوم وبينفصلوا.

## ٣) قاعدة البيانات (Firestore)
1. **Build ← Firestore Database ← Create database**.
2. النسخة **Standard**، والموقع الأقرب إلك (مثلاً `eur3 (Europe)`). **ما بيتغيّر بعدين.**
3. **Production mode** ← Create. (تخطّى النسخ الاحتياطي: بدو خطة مدفوعة.)

## ٤) القواعد
1. تبويب **Rules** بالـFirestore.
2. امسح كل شي والصق محتوى `firestore.rules` ← **Publish**.

## ٥) إعدادات التطبيق
1. ⚙️ **Project settings ← General ← Your apps ← أيقونة الويب `</>`**.
2. اسم التطبيق (مثلاً `studybuddy-web`) وما تفعّل Hosting ← Register app.
3. بيطلع كود فيه `const firebaseConfig = { ... }`. **انسخ الكتلة كاملة** من `{` لـ`}`.
   - استعمل تطبيق **الويب** مو أندرويد. ما بدنا `google-services.json`.

## ٦) الربط
**جهاز الأهل:** افتح التطبيق ← "هالجهاز لولي الأمر" ← رمز ← الصق الإعدادات وسجّل بإيميلك وكلمة سر (٦ خانات على الأقل) ← "اعمل كود ربط" ← "انسخ الكود" وابعتو لجهاز الطالب.

**جهاز الطالب:** قسم الأهل ← "ربط الأهل مع الطالب" ← الصق الكود ← اربط. الكود صالح ١٠ دقايق.

بعدها الطالب بيحلّ درس، وبعد ثواني بيطلع بجهاز الأهل.

## إذا ما اشتغل
| الرسالة | السبب |
|---|---|
| القواعد (Rules) مو منشورة أو ما بتسمح | ما نشرت القواعد، أو نسختها ناقصة |
| فعّل Email/Password وAnonymous | الخطوة ٢ |
| الكود انتهت صلاحيتو | اعمل كود جديد |
| مفتاح Firebase (apiKey) مو صحيح | نسخت إعدادات غلط (لازم تطبيق الويب) |

## حدود الخطة المجانية (Spark)
٥٠ ألف قراءة و٢٠ ألف كتابة باليوم، و١ غيغابايت. عيلة بتكفيها بسهولة.
